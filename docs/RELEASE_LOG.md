## v0.4 — Quality Gate 履歴の絞り込み

- **公開日**：2026-07-01
- **変更点**：判定履歴を「すべて / 採用 / 保留 / 捨てる」で絞り込むボタンを追加。絞り込み中も削除・Markdownコピーは動作。絞り込み結果0件時の空状態も表示。
