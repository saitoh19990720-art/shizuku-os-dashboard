# FEEDBACK_LOOP.md｜公開後の反応を、改善と次の制作に戻す

> 作って終わりにしない。反応を見る → 改善に変換 → 次タスク/Obsidianに戻す。
> SNSは宣伝でなく「外界センサー」。疲れない運用で。最終更新：2026-07-02

---

## どこから反応を見るか（見る項目）
| 場所 | 見るところ |
|---|---|
| X | いいね／保存／引用／返信／プロフィール遷移 |
| note | スキ／読了感／コメント／次に読まれたいテーマ |
| GitHub | READMEの伝わりやすさ／スター／初見での分かりやすさ |
| Vercel（実物） | スマホ表示／第一印象／操作の分かりやすさ |

## 反応を改善に変換するルール（鵜呑みにしない）
数字だけで判断しない。次の5分類に振り分ける：
- **すぐ直す**（明確な不便・崩れ）
- **次回改善**（v0.12以降）
- **保留**（様子見）
- **捨てる**（方向と合わない）
- **別作品に回す**（この作品の芯ではない）

## 疲れない運用
- 1回の投稿で完結させない。分割して育てる。
- 反応チェックは1日1回でいい。落ち込む指標は追わない。
- 記録は下のテンプレに3分で。合わなければ「捨てる」でOK。
